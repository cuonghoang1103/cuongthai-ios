# CuongThai for iOS

The native SwiftUI app for **[cuongthai.com](https://cuongthai.com)** — a
bilingual (Vietnamese / English) learning platform for IT students — on iPhone
and iPad. It talks to the same REST API as the website
([api-backend](https://github.com/cuonghoang1103/api-backend)) and ships to
testers through TestFlight.

**How it's built:** I design the features and break them into tasks, an AI
coding agent (Claude Code) writes much of the Swift, and I test it on the
simulator and on real devices, ship builds to TestFlight, and fix what breaks.

## What's in it

**Learning** — courses and lessons from the platform, downloadable for offline
use on iPad · an IELTS track with a daily path (streaks, XP), speaking practice
graded by AI, and a timed exam room · video lessons with bilingual subtitles:
tap a sentence to seek, ask the AI about the video and get clickable `[mm:ss]`
answers · Japanese kana/kanji practice with Apple Pencil · a code lab, an
algorithm visualiser, simulations and PDF books.

**Making things** — a handwritten notebook (PencilKit) with a split
reading/writing view on iPad · a drawing workshop (freehand and shapes, PNG
export) · a 3D workshop: build from blocks, Boolean union/subtract/intersect,
undo/redo, gizmos, export to `.usdz`, `.glb` and `.obj`, preview in AR.

**Everyday** — personal finance with home- and lock-screen widgets and a Siri
shortcut to log spending · a CV builder · interview practice.

**Community** — feed, realtime direct messages, voice/video calls, push
notifications, and the moderation App Review requires: filtering, reporting,
blocking and published contact details.

**Account** — Sign in with Apple or Google, in-app account deletion, Pro through
in-app purchase.

## Engineering notes

- **The server decides who is Pro.** The app never trusts an entitlement it
  worked out itself: it asks `GET /api/v1/profile`, every Pro gate is enforced
  in the backend, and the app only shows what the server says. That is also
  why a plan bought on the website works in the app straight away.
- **App Review rules live in the repo.** [`CLAUDE.md`](CLAUDE.md) turns the
  guidelines this app is exposed to — in-app purchase for unlocks (3.1.1),
  account deletion (5.1.1(v)), user-generated content (1.2), consent before
  sending data to an AI provider (5.1.2(i)), the privacy manifest — into rules
  checked before every submission.
- **One layout for iPad and Mac.** The layout is chosen by
  `horizontalSizeClass`, not `#if os(...)`, so the same `NavigationSplitView`
  serves an iPad in landscape and the experimental Mac target.
- **The share extension never calls the API.** It has no login token (that
  stays in the main app's Keychain) and very little memory, so it only writes
  the shared link into the App Group — *before* waking the app, or the app can
  read the group too early and find nothing.

## Bugs that taught me something

- **A new field wiped users' saved 3D models.** Swift's synthesised `Decodable`
  requires every key — even for a property with a default value — so files
  saved before the field existed threw `keyNotFound`, and the loader's
  `compactMap { try? decode(...) }` turned that into an empty list with no log.
  Fix: a hand-written `init(from:)` that uses `decodeIfPresent` for every field
  added after the first release.
- **A `let` with a default value is never decoded.** `let provider: String? = nil`
  decodes `{"provider":"google"}` as `nil`. The compiler only warns; at runtime
  it is silent. API model fields are `var` and optional.
- **`BUILD SUCCEEDED` didn't mean the screen had changed.** Builds go to a
  custom DerivedData folder; installing from Xcode's default hashed folder
  deployed a months-old binary. The build notes now pin the exact output path.

## Targets

| Scheme | What it is |
|---|---|
| `CuongThaiApp` | The app — iPhone and iPad |
| `TienWidget` | Finance widgets for the home and lock screen |

## Building

```bash
brew install xcodegen
xcodegen generate
open CuongThaiApp.xcodeproj   # scheme: CuongThaiApp
```

Choose your own team under *Signing & Capabilities*. The app talks to the
production API at `https://cuongthai.com` by default.
